# Contributing

Thank you for your interest in METIS. Bug reports, documentation improvements, and reproducibility contributions are welcome.

## Suggested Contributions

- fix documentation typos
- add dataset citation links
- improve preprocessing notes for public datasets
- add reproducibility checks for benchmark scripts
- report unclear prompt templates or missing metadata

## Reporting Issues

When reporting a bug or reproducibility issue, include:

- operating system and Python version
- package versions
- dataset and split
- command used
- expected behavior
- observed behavior
- relevant logs

Please do not upload private clinical data, protected health information, or restricted dataset files to issues.

By contributing code, you agree that your contribution will be licensed under the repository's [Apache License 2.0](LICENSE).
